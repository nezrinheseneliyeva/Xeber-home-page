# Xəbər Portalı Layihəsi

## 🚀 Texnologiyalar
Layihədə istifadə olunan əsas texnologiyalar:
- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Fetch API** (Məlumatları API-dən çəkmək üçün)
- **LocalStorage** (Məlumatları yadda saxlamaq üçün)

## 📌 Əsas Funksiyalar
- **Ana səhifə:** Ən son xəbərlərin siyahısı.
- **Daha çox oxu:** Xəbərlərin ətraflı məzmununa keçid.
- **Dinamik Məzmun:** API-dən gələn məlumatların avtomatik render edilməsi.
- **Sidebar:** Canlı xəbər başlıqları.

## 🛠️ Quraşdırma
1. Bu repozitoriyanı klonlayın:
   `git clone https://github.com/nezrinheseneliyeva/News-portal-API.git`
2. Qovluğa daxil olun.
3. `index3.html` faylını brauzerdə açın.
